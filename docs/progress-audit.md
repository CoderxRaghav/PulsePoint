## Phase 7 — AI Assistant (founder decision, 2026-11-17 — documentation only)

Status: **Phase 7A APPROVED FOR IMPLEMENTATION, NOT YET IMPLEMENTED.** No code, packages, env vars, routes, or migrations exist. Provider/scope decision recorded by founder 2026-11-17; full architecture, security rules, privacy disclosure, free-tier constraints, failure handling, and deferral list live in **`docs/ai/assistant.md`**.

Decision:
- Build an **All-in-One PulsePoint AI Assistant** (long-term capabilities: 1. general knowledge Q&A · 2. secure, permission-aware retrieval of PulsePoint data · 3. project mentoring · 4. real-time external information via separately approved providers).
- **Provider changed: Groq API (OpenAI-compatible), not Gemini.** Intended initial model: `openai/gpt-oss-20b`. This supersedes only the provider portion of the original Gemini-era gate; the founder-approval gate itself stands.
- **Phase 7A scope (approved, not started):** authenticated assistant endpoint (Firebase ID token verified server-side) · general knowledge responses · basic caller-scoped PulsePoint context · minimal assistant UI · **no** external real-time providers · **no** conversation persistence · **no** database migrations · **no** write operations · **disabled by default** (missing config/flag = off; e.g., 503 + hidden UI).
- **External data providers require individual approval** and must never be accessed through arbitrary URLs — no fetch-by-URL capability at any phase. Groq inference is approved for 7A only; Groq built-in tools (browser search, code execution, connectors, remote MCP) are **not** authorized. Per-provider approval ledger: `docs/ai/assistant.md` § "External providers & approval ledger".
- Privacy disclosure (Groq as third-party processor, US data location, 7A non-persistence, Groq retention/ZDR summary, no secrets/PII of others) is a hard requirement for the 7A UI — see `docs/ai/assistant.md`.
- Free tier (Nov 2026, org-level, verify at implementation): 30 RPM / 1,000 RPD / 8K TPM / 200K TPD for `openai/gpt-oss-20b`; 8K TPM is the binding constraint → compact prompts, small `max_completion_tokens`, per-user throttle, honest 429 handling; free tier is build/test-grade, not sustained traffic.
- Failure policy: fail closed for permission/safety issues, fail honest otherwise; no automatic fallback to other providers or scraped sources; never fabricate PulsePoint data.

Not done (at decision time): everything — the documentation-only phase added no code. Later phases (7B retrieval, 7C mentoring, 7D real-time providers, 7E persistence, 7F write actions) each require separate founder approval. The original roadmap decision is preserved verbatim in "Next in roadmap order" below (Gemini mention retained as history, annotated with the 2026-11-17 change). **See the 2026-11-17 implementation entry below, which supersedes the "not yet implemented" statements in this section.**
